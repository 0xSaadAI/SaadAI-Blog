# SaadAI-Blog

is an independent Arabic blog focused on:
Artificial Intelligence (AI), Data Science (DS), Machine Learning (ML), and Computer Science (CS).

## Purpose
- Simplify technical concepts for Arabic readers
- Publish concise articles with practical examples
- Build a useful Arabic knowledge base for beginners and intermediate learners

## Content
- AI / DS / ML articles
- Tutorials on tools and libraries
- References and learning resources with each post

## Built with :
- R : Statistical programming language
- Quarto : Static library for r language generating html files
- Markdown : Used to write posts
